本仓库只保存**文档**与**歌曲成品**，不含任何模型权重、虚拟环境与中间产物。

## 曲目信息

- **曲风**：Genre-bending avant-garde art pop × alternative rock × electronic；暗黑艺术流行 / 哥特交响 / 教堂管风琴，110 BPM，男声高音（约四个八度）
- **成品**：`绯红王座V6_6.wav`
